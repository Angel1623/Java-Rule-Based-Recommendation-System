# Rule-Based Recommendation System

## About the Project

This project is a Java-based Rule-Based Recommendation System developed during the AICTE–EduSkills Virtual Internship.

The system analyzes user activities such as views and likes, tracks user interests, maps items to categories, and generates a category-based recommendation using predefined rules.

## Internship Details

- **Internship:** AICTE – EduSkills Virtual Internship
- **Duration:** 8 Weeks
- **Technology:** Java
- **Development Tool:** Visual Studio Code
- **Project Title:** Rule-Based Recommendation System

## Objectives

- Process user activity logs.
- Count item views and likes.
- Identify the top liked item.
- Map items to their categories.
- Calculate category-wise likes.
- Recommend the category with the highest user interest.

## Features

- User activity processing
- View counting
- Like counting
- Top liked item identification
- Category mapping
- Category-wise interest calculation
- Rule-based recommendation

## Technologies Used

- Java
- Visual Studio Code
- Java Collections
- HashMap
- Scanner
- Conditional Logic

## How the System Works

1. The user provides item-category mappings.
2. The system receives user activities such as `VIEW` and `LIKE`.
3. Views and likes are counted.
4. The system identifies the item with the highest number of likes.
5. Likes are grouped based on item categories.
6. The category with the highest interest is recommended.
